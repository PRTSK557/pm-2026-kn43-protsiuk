## 1. Definition of Workflow

| Колонка | Картка потрапляє сюди, коли | Картка виходить звідси, коли |
| --- | --- | --- |
| Backlog | картка має ключ `F-0NN` і назву з дієсловом, яка називає один результат (файл або розділ файла) | можна одним реченням сказати, що вважається її завершенням, і роботи на ній не більше ніж на 1-2 дні |
| Ready | у картці записано, у якому файлі з'явиться результат, а в In progress є вільне місце в ліміті | я почав працювати над нею, і в полі «У роботі з» стоїть дата |
| In progress | у полі «У роботі з» стоїть дата старту, і картка займає місце в ліміті | зміни збережено у файлі репозиторію, і їх можна відкрити й прочитати |
| Review | результат лежить у репозиторії, і його можна перевірити: валідатор для CSV, чекліст самоперевірки з умови для Markdown | валідатор не дає помилок або всі пункти чекліста виконано, і зміни закомічено |
| Done | є коміт із результатом, і в полі «Завершена» стоїть дата | картка лишається тут: з Done вона переїде в `lr14_metrics/flow.csv` |
